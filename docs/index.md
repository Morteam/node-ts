# NODE JS

Es un **Runtime Environment**, habilita un ambiente para ejecutar JS desde alcances distintos a un Browser, en la mayoria de los casos se usará del lado del Server.

Está construido con el motor V8 de Google Chrome, soporta:

* Tareas de entrada/salida
* Manejo de archivos en el client/server
* Asincronía
* Modulos nativos y de terceros
* Gestión de paquetes nativos / de terceros
* Construcción de servidores
* Escalabilidad
* Multiplataforma
* Single Thread no bloqueante (Non-blocking I/O - Input/Output), es decir podemos tener cientos de peticiones sin bloquear el Server, gracias a una librería llamada **Libuv**
* Node cuenta con funciones tanto síncronás como asíncronas


**NPM:** Node Package Manager
**NPX:** Node Package Execute, permite ejecutar paquetes sin la necesidad de tenerlos instalados
**I/O:** Input/Output se refiere a la interacción con el Disco Duro del sistema
