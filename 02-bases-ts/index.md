# Bases

* Start Node project `npm init`
* Start Node project with all default values `npm init -y`

* Install all packages that appear in the package.json file `npm i`
* Install just a package like dependency `npm i {{package name}}`
* Install just a package like development dependency `npm i -D {{package name}}`
* Install just a package (way global) `npm i -g {{package name}}`

### Useful packages

* Nodemon: `npm i -g nodemon`
* Winstons: `npm i -g nodemon`, allows us to log something but it's very useful to host in a transport (for example server, log files, etc)


`process` contains all data about Node JS processing
