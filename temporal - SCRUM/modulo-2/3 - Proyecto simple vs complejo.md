## Complejidad: Proyecto Simple vs Complejo

Clasificación de Proyectos basados en la complejidad

| Proyecto | Simple | Complejo |
|----------|----------|----------|
| Claridad del Objetivo    | Alta   | Aceptable   |
| Riesgos   | Bajos   | Medios o Elevados   |
| Innovación    | Baja   | Alta   |
| Experiencias y Conocimientos | Altos | Variados |
| % Exito | Alto | Variable |


Para Proyectos Simples se recomiendan metodologías tradicionales como por ejemplo Waterfall, mientras que para Proyectos Complejos se recomienda el uso de Agile.
